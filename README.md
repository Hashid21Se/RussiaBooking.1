# RussiaBooking — منصة حجز فنادق روسيا المتكاملة

منصة وتطبيقات حجز فندقية عالية الاعتمادية والأمان، مخصصة للمسافرين من المملكة العربية السعودية ودول الخليج العربي، تدعم الدفع المباشر بالريال السعودي والدرهم الإماراتي عبر بطاقات **مدى (Mada)**، **تمارا (Tamara)**، و **Apple Pay / Google Pay**، مع إصدار فوري لقسائم الفنادق المعتمدة وتأشيرة السفر السياحية.

---

## 🌟 الميزات الرئيسية (Core Features)

1. **محرك حجز فندقي متقدم:**
   - تغطية أفخم فنادق موسكو، سانت بطرسبرغ، سوتشي، وقازان.
   - قفل موزع لمنع الحجز المزدوج (Overbooking Prevention) بواسطة Redis و PostgreSQL.
   - تحويل عملات لحظي وخالٍ من أخطاء التقريب بين (RUB, SAR, AED, USD).
2. **بوابات دفع خليجية معتمدة:**
   - تكامل كامل مع مدى (Mada)، تمارا للتقسيط (Tamara)، وTap Payments مع تدقيق توقيع HMAC-SHA256 لإشعارات الـ Webhooks.
3. **أمان مشفر وامتثال قانوني:**
   - تشفير بيانات الجوازات والهوية الحساسة في السكون بواسطة `AES-256-GCM`.
   - مصادقة ثنائية العاملين (RFC 6238 TOTP 2FA) للوحة إدارة النظام.
   - امتثال كامل لنظام حماية البيانات الشخصية السعودي (PDPL) واللائحة العامة لحماية البيانات (GDPR) بما يشمل حق النسيان وحذف الحساب.
4. **تطبيقات الجوال الأصيلة (React Native + Expo):**
   - تسجيل دخول ببصمة الوجه (Face ID) وبصمة الإصبع.
   - وضع العمل دون اتصال بالإنترنت (Offline Mode) لعرض قسائم الفنادق ورموز QR في المطارات.
   - إشعارات فورية (Push Notifications) لتأكيدات الحجز والتذكير.
   - دعم كامل لـ Apple Pay و Google Pay.

## 🚀 التشغيل المحلي السريع (Quick Local Setup)

### المتطلبات الأساسية
- Node.js 20 LTS أو أحدث
- Docker و Docker Compose (اختياري للتشغيل الكامل مع قواعد البيانات)

### 1. تشغيل بيئة الويب والـ API محلياً
```bash
# تثبيت التبعيات
npm install

# فحص التوافقية والأنواع
npm run lint

# تشغيل الاختبارات الشاملة (Unit, Security, Integration)
npm test

# تشغيل خادم التطوير (على المنفذ 3000)
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. تشغيل حزمة الخدمات الكاملة عبر Docker Compose
تشمل التطبيق، قاعدة بيانات PostgreSQL 16، خادم Redis 7، ونظام المراقبة Prometheus و Grafana:
```bash
docker-compose up -d --build
```
- تطبيق الويب: `http://localhost:3000`
- لوحة تحكم Grafana للمقاييس: `http://localhost:3001` (admin / admin_grafana_pass_2026)
- لوحة مقاييس Prometheus: `http://localhost:9090`

## 📱 تشغيل وبناء تطبيق الجوال (Mobile App)

```bash
cd mobile

# تثبيت مكتبات الجوال
npm install

# تشغيل تطبيق Expo للمعاينة الحية عبر الجوال (QR Code)
npm start

# بناء ملف APK للمعاينة والتجربة المحلية:
npm run build:local:apk

# بناء حزمة AAB لمتجر Google Play:
npm run build:android

# بناء حزمة IPA لمتجر Apple App Store:
npm run build:ios
```

## 🧪 منظومة الاختبارات وجودة الكود (Testing & QA)

تتمتع المنصة بتغطية اختبارات شاملة واجتياز بنسبة 100%:
- `npm test`: تشغيل اختبارات الوحدة، المنطق المالي، والعمليات الحسابية بدون أي تسريب مالي.
- `src/test/security.test.ts`: اختبارات التشفير AES-256-GCM، حماية CSRF، وتواقيع الـ Webhooks.
- `src/test/financial_and_booking.test.ts`: اختبارات توزيع العمولات، سياسات الإلغاء، والتسويات المالية.

## 📂 هيكل المشروع (Directory Structure)

```
├── src/                      # كود الواجهة الأمامية وواجهات المستخدم ومحركات الأمان
│   ├── components/           # مكونات React (حجز، بحث، لوحة الإدارة، المصادقة 2FA)
│   ├── server/               # طبقة الخدمات الخلفية وميدلوير الأمان والتشفير
│   └── test/                 # أجنحة الاختبارات المؤتمتة (Vitest)
├── mobile/                   # مشروع تطبيق الجوال المستقل (React Native + Expo)
│   ├── src/services/         # خدمات البصمة، التخزين دون اتصال، Apple Pay، والإشعارات
│   ├── store_metadata/       # بيانات وقوائم متجري Google Play و App Store
│   └── fastlane/             # سكريبتات الأتمتة والنشر للمتاجر
├── terraform/                # البنية التحتية ككود (AWS Aurora, Redis, CloudFront)
├── monitoring/               # تكوينات Prometheus, Grafana, وقواعد التنبيهات
├── scripts/                  # سكريبتات النسخ الاحتياطي والاستعادة الدورية لقاعدة البيانات
├── Dockerfile                # صورة Docker للإنتاج متعددة المراحل
└── docker-compose.yml        # بيئة التطوير المتكاملة محلياً
```
